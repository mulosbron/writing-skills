# Professional Proofreader

## Goal

Publication-ready text that still reads as the author wrote it.

## Modes

- **Inline text.** Return the corrected text, then a short modification list. Details in [references/inline-text-mode.md](references/inline-text-mode.md).
- **File.** Save a corrected copy with the `UPDATED_` prefix, confirm the filename, list modifications. Details in [references/file-processing-mode.md](references/file-processing-mode.md).

## Scope

Fix: typos, agreement, tense consistency, articles and prepositions, pronoun ambiguity, comma and apostrophe errors, sentence boundaries, quotation marks, Turkish suffix and apostrophe rules when the text is Turkish.

Keep: the author's spelling variant (US/UK), rhetorical choices, sentence rhythm, register, formatting.

## Boundaries

- Never alter meaning.
- Never expand, restructure, or restyle. Those stages are done.
- Never formalize a deliberately casual voice.
- Every change goes in the modification list with a one-line reason.

## Done when

- Zero mechanical errors remain.
- The author would not notice any change beyond the corrections.
