# Live Stream Mega-Guide & Lead Magnet Skill

## Purpose
Automate daily live stream preparation and lead-magnet creation from a single `topic = ...` prompt, producing a structured, emoji-formatted, presenter-ready guide.

## Input
- `topic`: The tool, workflow, or masterclass subject.
- `offer_name` & `offer_url` (optional): Community or product CTA to weave throughout.

## Research Step (When Web Access Is Available)
Research 10–20 current sources on `topic` to pull real features, official links, live demo ideas, and up-to-date use cases.

## Required Document Architecture (Exact Order)
1. **Labeled Intro & Opening Hook**:
   - Exact first-30-seconds script to stop the scroll and state the big promise.
   - Quick-reference list of live demo URLs to show on screen.
2. **Custom Named Framework + Subheadline**:
   - Package the workflow into a memorable 3–5 step named framework with a punchy subheadline.
3. **Belief-Breaking Section (False Beliefs -> New Beliefs)**:
   - 3–5 pairs formatted as: *"You might believe [Old Limiting Belief], but actually [New Empowering Truth + Proof]."*
4. **Hook – Story – Offer (Russell Brunson Webinar Flow)**:
   - **Hook**: Core curiosity angle.
   - **Story**: Relatable transformation narrative (before -> bottleneck -> breakthrough -> after).
   - **Offer**: Value stack + natural CTA to `offer_name` / `offer_url`.
5. **Live Demo Walkthroughs**:
   - 3–5 concrete step-by-step builds to demonstrate live on stream.
6. **30-Day Implementation Plan**:
   - Day-by-day or week-by-week actionable checklist with step-by-step execution notes.
7. **Social Media Promo Pack**:
   - Ready-to-paste promotional posts for X, LinkedIn, YouTube Community, and Skool (with `[INSERT YOUTUBE LINK]` placeholder).
8. **100 Topic-Specific Prompts**:
   - Categorized library of 100 practical, copy-paste prompts tailored specifically to `topic` (Beginner, Content, Automation, Coding/Tools, Business Growth).

## Formatting Standards
- Use clear section labels and clean emojis as visual anchors so the presenter can scan live on air.
- Insert natural, non-pushy CTAs throughout the guide so it doubles as a downloadable lead magnet.
