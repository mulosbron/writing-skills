# Video Script Preparation

Use this skill whenever drafting, editing, or outlining a YouTube or educational video script.

## Formatting & Style Rules
1. **Spoken English**: Write in natural, conversational spoken English—short sentences, active voice, easy to read aloud without stumbling.
2. **Define Jargon Inline**: Whenever introducing a technical term (e.g., RAG, MCP, episodic memory, harness), immediately explain it in plain English within the same sentence or the very next sentence.
3. **No Em Dashes**: Never use `—` (em dashes). Use commas, periods, or short separate sentences instead.
4. **Concrete Examples**: Pair every abstract architecture concept with a quick, tangible real-world example or live walkthrough step.
5. **Mandatory Closing Catchphrase**: End every video script with the exact line:
   `You can build anything, you can learn anything.`
